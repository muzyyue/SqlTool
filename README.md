# SQL生成工具 (SqlTool)

根据DDL语句和Excel数据快速生成INSERT/UPDATE SQL语句。

## 功能特性

- 🔍 智能DDL解析 - 支持MySQL、PostgreSQL、SQL Server语法
- 📊 Excel数据导入 - 支持.xlsx、.xls、.csv格式
- ⚡ SQL生成 - INSERT/UPDATE语句批量生成
- 🎨 SQL美化 - 格式化和语法验证
- 🔧 批量修改 - 支持条件筛选和数据类型验证

## 快速开始

```bash
pnpm install
pnpm dev
```

访问 http://localhost:5173

## 使用流程

1. 输入DDL语句
2. 上传Excel文件
3. 配置字段映射
4. 生成SQL语句

## 技术栈

- Vue 3 + Composition API
- Vite 7.x
- Ant Design Vue 4.x
